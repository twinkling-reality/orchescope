## The work

Ordered by how much of the claim each one carries. Each is verified; each cites source.

### 1. Ship a source-identity producer

**This is the one that matters.** The join's strongest rule is `code_location`
(`packages/graph/src/reconcile.ts:41-47`). Across every traced third-party entry it fires **three times, all
on one entry**, and its producer is `corpus/instrumentation/crewai_source_identity.py`, which
`scripts/package.mjs` stages in nothing. Thirteen of seventeen joins are `kind_and_name`, which
`packages/schema/src/reconciliation.ts:82-88` calls the weakest and records as having already matched the
wrong module.

**The mechanism is already proven and already written.** `corpus/instrumentation/node_source_identity.mjs`
is 172 lines using `getCallSites` from `node:util`, and it writes `code.file.path`. Three siblings exist
beside it. None ships.

**It is not a drop-in.** Its gates require a clean checkout, a forty-character HEAD, an `origin` remote with
a credential-free HTTPS URL and a tracked file, because the corpus needs pinned identity for federation. A
user's working tree is usually dirty and often has no remote. Those gates have to become "is this path under
the audited root".

**Everything about cost and reach is already measured. Do not measure it again.**

- A bounded capture costs 3,250 nanoseconds at five frames and 9,256 at twenty, on Node, and the cost tracks
  the bound and not the stack: flat from depth 5 to depth 200. `getCallSites` is about 1.5 times that and is
  **not** flat past a bound of 20.
- Twenty frames reaches the repository's own file through all four Node stacks measured, including `ai` over
  `@ai-sdk/openai` at index 16 and `@openai/agents` at index 13. Five reaches one of four.
- The shim already costs 21,417 nanoseconds per request, 18.3 per cent of a bare loopback request. A twenty
  frame capture is seven per cent of an instrumented one.
- 28 bytes allocated per capture, nothing retained, **only because the rule reads the file and line and
  drops the frames.** A `CallSite` retains the receiver and function of its frame.
- `Error.stackTraceLimit` and `Error.prepareStackTrace` are process-wide and must both be saved and restored
  synchronously, or the shim reshapes every stack the target itself takes.
- The tail-return hazard is real in the language and absent from the code: **0 of 823 model-call sites**, and
  786 of 823 are awaited by the repository's own function.

**Two ceilings you are not going to remove, and must not pretend to.** On a built application
`getFileName()` returns the build output, in all seven source-map configurations tested, and **zero of the
eleven built packages in the corpus that hold a model call ship a runtime source map**. And a framework that
streams reaches the transport from its own scheduler with **no repository frame on the stack at any bound**,
in three of eight cases measured. Ship the producer for the population it serves and say in its header what
it does not reach.

## Known limits, recorded and not fixed

- `namesDefinedPackage` over-claims: `dbos`, `prefect` and `mcp` read as first-party on repositories holding
  directories of those names. Bounded for layer 1 by using the narrow gate.
- `CallKind = 'decorator'` is declared at `packages/source-analysis/src/facts.ts:99` and produced zero times
  in 759,081 calls.
- `DefinitionFact.returns` is never populated for JavaScript or TypeScript. `returnsOf` exists only in
  `packages/source-analysis/src/python/analyze.ts:1498-1533`.
- The JavaScript analyzer discards the source module of `export { X } from "spec"`, making 1,083 real
  re-export bindings unreadable.
- `resolvePython` is narrower than `namesDefinedPackage`, so 3,668 specifiers are refused as local by a broad
  rule and cannot be resolved by a narrow one.
- Nine recognition names match no pinned repository, reported every corpus run.
- **Python has no `fetch`.** `openai` 3.3.1 sends through `httpx2` 2.12.0, not `httpx`. A Python shim's
  transport list is a catalogue that has already decayed once inside one vendor's own SDK.

## Hard rules

- **NO GUESSING.** Verify every claim against source before acting on it. Cite `file:line`.
- **Gates that must be green before you say anything is done.** Report real numbers, never "tests pass":

      pnpm check              exit 0, 13 documents, 520 modules cruised
      pnpm test               1727 pass, 0 fail, 369 suites
      pnpm test:metamorphic   591 pass, 0 fail, 113 suites
      pnpm test:e2e           216 pass, 0 fail, 47 suites

                              87 recognition names, 78 matched, 9 matched none

  `pnpm test` does not run `tests/e2e/**`. Quote five numbers, not four. Add `pnpm corpus --exercise` if you
  touch the runtime join, which item 1 does.
- **CORPUS REBASELINE NEEDS EXPLICIT APPROVAL**, with the entry, the before, the after and why, per entry.
  `--record` does not touch the hand-written `acceptance` blocks in `corpus.yaml`.
- **Every fix gets a regression pin that is a REAL FALSIFIER.** Prove it: run the new test against the old
  tree and show it failing, then against the new and show it passing. A test that passes both ways is a
  **guard**, which is legitimate and required, but it must be labelled as one and never counted as a
  falsifier. The working recipe, validated by poisoning the old tree and watching it fail:

      REPO=/Users/glendonchin/dev/Technology/orchescope
      BASE=$(git -C "$REPO" rev-parse HEAD); OLD=/tmp/old-$BASE
      rm -rf "$OLD" && mkdir -p "$OLD"
      git -C "$REPO" archive "$BASE" | tar -x -C "$OLD"
      ln -s "$REPO/node_modules" "$OLD/node_modules"
      cd "$REPO" && find packages apps -maxdepth 2 -name node_modules -type d |
        while read -r nm; do cp -RP "$nm" "$OLD/$nm"; done
      git -C "$OLD" init -q && git -C "$OLD" add -A &&
        git -C "$OLD" -c user.name=old -c user.email=old@old commit -qm "$BASE"
      ln -s "$REPO/corpus/.cache" "$OLD/corpus/.cache"

  **`cp -RP`, never `ln -s`.** Every workspace link here is relative, so symlinking a per-package
  `node_modules` makes it realpath back into the live repository and the falsifier silently tests the new
  source and passes both ways. Measured: the wrong recipe gives 36 pass 0 fail against a poisoned old tree.
- **Land in separable commits, each with its own corpus gate**, so a genuine regression cannot hide inside a
  wide diff.
- **Commits**: single line, imperative, no trailers of any kind, no AI authorship notice, no em dash
  characters anywhere in code, comments, docs or commit messages. Use:

      git -c core.hooksPath= -c user.name='Glendon Chin' -c user.email='glendonchin@gmail.com'

  Never use `gh pr merge`. Do not publish to npm. Do not tag.

## The bar

Every one of these three items has an easy version that would pass its tests and be wrong.

**Item 1's easy version** is a stack capture with a hardcoded frame count and a list of framework paths to
skip. That is the catalogue, rebuilt in the runtime half, which is the one half ADR 0015 says does not have
one. The producer must decide "is this frame the repository's" by asking the audit root, and nothing else.

**Item 2's easy version** is adding the flag and moving on. The comment at `create.ts:86-96` argues that a
criterion whose deciding command is not named should be omitted rather than reported not applicable. Read it
and decide whether the flag is the whole fix or whether the plan's contract needs the same care.

**Item 3's easy version** is writing three scenarios for one repository and declaring the loop general. A
scenario that only its author can write is the fixture problem with more files. What makes item 3 true is
that an operator who is not you can produce one, which is a question about `orchescope init` and the
scenario schema before it is a question about YAML.

**And the standing bar from the last session, which produced every good decision in it:** measure against
all 56 repositories before writing code, never a sample. A fourteen-repository sample supported a change the
full corpus refuted. The corpus cache at `corpus/.cache` is populated. Use it as an instrument, not as a
gate you run at the end.
