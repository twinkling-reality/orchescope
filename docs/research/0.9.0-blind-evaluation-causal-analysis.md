# Causal analysis of the 0.9.0 blind evaluation

This record turns the independent evaluation of `orchescope@0.9.0` into defect families. It does not treat one
repository as a specification. Each family names the producer, the consumer that lost or overstated the fact, the
population that shares the assumption, and the observation that would falsify the proposed correction.

## Evidence boundary

The evaluation audited `langchain-ai/local-deep-researcher` at
`a53b13c7022bb1352dc1ca994d07ade3cd3bd62e` with the published package. Its static export contains 15 components
and 11 relations. Its observed export contains 16 components and 14 relations. The stored run contains 16 spans:
one graph span, eight node spans, two router spans, and five `ChatOllama` spans. The export retains 13 span evidence
records and does not state why the graph and router spans are absent.

The evaluation artifacts remain read-only under
`/Users/glendonchin/dev/Technology/orchescope-eval-0.9.0`. The product conclusions below depend only on reviewed
source, exported documents, and the stored SQLite rows. Target installation artifacts such as egg-info and
`__pycache__` are environment effects and are not product evidence.

## Complaints that do not identify product defects

- `START` and `END` are virtual LangGraph boundary sentinels. They do not belong in displayed agent topology or runtime
  exercise denominators. Losing their handled status is a completeness defect; omitting sentinel components is not.
- `edgeExerciseRate: 0` is correct for this run. Repeated or sequential component execution does not identify a
  particular source, destination, and trigger for a declared handoff. Behavioral narrative must improve without
  manufacturing relation evidence.
- `not_a_node_target` is the honest Python auto-instrumentation boundary. The first command completed with zero spans;
  the second still reported no injection and accepted operator-supplied OpenTelemetry and OpenInference spans.
- Exact runtime model `smollm2:135m` must remain unmatched because the operator selected it through environment
  configuration and the source contains no matching exact literal.
- Five agent joins by kind and name and zero code-location joins are correct. OpenInference supplied names and model
  identity but no file, line, repository, or revision attributes.
- The graph and router spans are structural observations, not additional agents. Their omission from the component
  population is correct; an export using or omitting their evidence must say which.
- The measured percentages carry a basis and sample size. The 71 percent denominator is wrong because a false Postgres
  component entered it, not because the arithmetic was invented.
- Installation, doctor, colour behavior, redaction, Mermaid truncation, and the read-only audit summary passed their
  evaluation checks.

## Stage ownership

One owner edits each shared responsibility during implementation:

| Responsibility | Owned modules |
| --- | --- |
| Semantic finding identity | `packages/domain`, `packages/findings`, goal compatibility paths |
| Topology facts and completeness | `packages/source-analysis`, LangGraph adapter, topology analysis and strengths |
| Provider-qualified identity | effects matching and the common imported-origin matchers it calls |
| Model and configurable effects | model and effects adapters plus their focused fixtures |
| Runtime and report truthfulness | trace export accounting, report bundle, terminal and MCP projections |
| Release protocol and corpus | corpus definitions, expectations, release guide, and holdout protocol |

An edit that needs another responsibility waits for that owner rather than creating a second implementation of the same
domain rule.

## Acceptance invariant

Incomplete evidence may produce a bounded blind spot or refusal. It may not produce an absence-based strength. A fix is
general only when its falsifier passes on a small deterministic fixture and the exact pinned third-party repository,
while the existing negative and exercised corpus invariants remain unchanged unless reviewed evidence explains the
movement.
