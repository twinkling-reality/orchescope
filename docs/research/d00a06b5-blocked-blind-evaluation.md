## Positive result and runtime boundary

CrossDiscipline Research Agent is an implemented hand-written multi-agent application. Its orchestrator constructs and
sequences five research stages; those stages build prompts, invoke a shared completion client and provide rule-based
fallbacks. The frozen package honestly reported that no installed framework adapter recognized the application. It
still discovered the shared HTTP completion call and its bounded retry without converting that support boundary into
an absence, strength or metric claim.

No runtime audit was executed. The target supplies no scenario, fixture input, recorded run or fake offline execution
mode. Its ordinary path needs an evaluator-selected research subject and outbound scholarly sources, and its model path
needs credentials. No research subject, external population, credential or substitute runtime was invented. The
completed-zero runtime record therefore makes no broader execution claim.

## Blocking negative-control identity

Agentgauge is agent-adjacent tooling, not an agent application. It reads existing coding-agent session logs, attributes
token use and cost, identifies producer fingerprints and renders reports. Its optional pricing-update command contains
a `fetch(url)` call inside the `async run({ args })` object method supplied to a command definition.

The frozen package instead created `entrypoint:module-scope`, described it as the enclosing scope of the external
effect, and originated the `calls_service` relation from that component. The call is evaluated only when the `run`
method executes. Its source span proves the call site but cannot support module-scope ownership. The same wrong identity
propagated into the external-service scope, finding population and Mermaid export. This is a publication-blocking wrong
component identity, not a display preference or an honest unsupported boundary.

The negative polarity itself was correct. Agentgauge remained classified as not an agent system, and no agent, model,
tool, strength or unbounded metric was invented. Those correct claims do not waive the unsupported ownership claim.

## Regression disposition

JavaScript and TypeScript object shorthand methods and function-valued object properties retain the smallest named
callable that owns their body, including when the object is nested inside a call argument. A direct top-level external
call remains module scope. An external call inside an unnamed callable receives an explicit ownership refusal instead
of borrowing the surrounding function or module. Effect components, caller relations, source evidence, findings and
exports consume the same callable identity.

The positive is pinned as a source-cited regression input at its evaluated revision. The negative contributes the
distinct precision invariant that exposed the defect and is also pinned at its evaluated revision. Neither regression
work nor a corrected scan changes this frozen decision or can clear the blocked candidate.
